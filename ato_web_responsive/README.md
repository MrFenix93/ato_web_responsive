# ATO Web Responsive

A modern responsive backend interface for Odoo 20.

## Features

- Responsive backend interface
- Application home menu
- Responsive navigation
- Light and dark appearance modes
- Responsive Pivot view
- Desktop, tablet and mobile support
- Designed for Odoo 20

## Compatibility

- Odoo 20.0
